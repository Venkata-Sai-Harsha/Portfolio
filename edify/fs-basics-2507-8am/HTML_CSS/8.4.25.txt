Padding: Adds empty space between border and content of element.

    Syntax:

        padding: 10px;

        padding-left: 20px;
        padding-top: 20px;
        padding-bottom: 20px;
        padding-right: 20px;

        padding: 20px 12px 34px 45px; (Clock wise direction) (top, right, bottom & left)
 
        padding: 20px 30px; (First value is top & bottom & Second value is left & right)

Margin: Adds empty space between border and other element.

    Syntax:

        margin: 10px;

        margin-left: 20px;
        margin-top: 20px;
        margin-bottom: 20px;
        margin-right: 20px;

        margin: 20px 12px 34px 45px; (Clock wise direction) (top, right, bottom & left)
 
        margin: 20px 30px; (First value is top & bottom & Second value is left & right)

Division: Groups a set of elements into one unit.

> It divides web page into different portions.

    Syntax:

        <div>
            // HTML Elements...
        
        </div>

Box Model: Margin - Border - Padding - Content
