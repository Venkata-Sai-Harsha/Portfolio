AJAX: 
> Stands for Asynchronous Javascript & XML (JSON)
> Used for sending information from FE to BE and vice versa.
> Updates the content of the web page without reloading it.
> Javascript provides predefined function which is XMLHttpRequest
> Internally AJAX, uses HTTP Protocol to communicate between applications.

    Hyper Text Transfer Protocol Security

        http

        https

    Creation of object:

        var httpRequest = new XMLHttpRequest();

            httpRequest.readyState - (0 - 4)

                If readyState is 4, indicates response is received in the frontend.

                0 - Request not initialized
                1 - Server Connection established.
                2 -	Request received.
                3 - Processing request.
                4 - Request finished and response ready.
